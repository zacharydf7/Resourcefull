# Security policy

## Supported versions

Security fixes go into the latest minor release of the current major version. Upgrade to it to get them.

| Version | Gets security fixes |
|---|---|
| The latest 3.x release | yes |
| Earlier releases | no |

## Reporting a vulnerability

Please don't open a public issue for a vulnerability: it would tell attackers about it before there's a fix.

Report it privately instead, through GitHub: on the repository's **Security** tab, choose **Report a vulnerability**.
In the report, include what's affected (the package and version, and the provider if it matters), how to reproduce
it, and what an attacker could do with it.

If that option isn't there, open an issue that only asks for a private way to send a report, without any details.

You should get a reply within a week. Once a fix is released, the report becomes a published security advisory, with
credit to you unless you'd rather not be named.
